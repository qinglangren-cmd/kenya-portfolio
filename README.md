# Beyond What We Know — Kenya Portfolio

A standalone GitHub Pages portfolio about a 10-day stay in Homa Bay, Kenya.

## Publish as a separate website
1. Create a new **Public** GitHub repository, for example `kenya-portfolio`.
2. Upload `index.html` to the repository root.
3. Upload the entire `assets` folder (keep the image files directly inside `assets`).
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. GitHub will provide a separate Pages URL. This will not change the Bali website.

All 20 supplied photographs are included in `assets`. The page uses responsive layouts and a click-to-enlarge gallery.
